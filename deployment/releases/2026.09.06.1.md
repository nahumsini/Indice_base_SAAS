## Security maintenance

The release scan identified vulnerable dependency versions in the previous candidate. Maintenance
updates stay on Spring Boot 3.5 and Tomcat 10.1: Boot 3.5.16, Tomcat 10.1.59, Jackson 2.21.6,
Thymeleaf 3.1.5 through the Boot BOM, MinIO Java 8.6.0 and Bouncy Castle 1.85.2.
OkHttp JVM 5.1.0 is explicit because the MinIO 8.6 Maven dependency requires the JVM artifact.

Container review also updates installed Alpine packages in the backend and web runtime images.
MCP retains Node 22 and its locked production dependencies, with an Alpine runtime that omits
npm, Yarn and build tools. Its build and runtime both use musl; the existing MCP regressions are
executed inside the final image before promotion. Runtime users remain unprivileged.

References: [Tomcat security fixes](https://tomcat.apache.org/security-10.html),
[MinIO Java advisory](https://github.com/minio/minio-java/security/advisories/GHSA-h7rh-xfpj-hpcm),
[OkHttp Maven/JVM dependency contract](https://github.com/square/okhttp#maven-and-jvm-projects).
