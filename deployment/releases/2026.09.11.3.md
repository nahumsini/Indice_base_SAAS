# v2026.09.11.3 — Petty Cash approval compatibility fix

Deployed application commit: `253dd88d8ec2256f08d701db0f21a37a059fb165` from `release/2026-09-11-finance-corrections`.

Approving a supported Petty Cash receipt could return HTTP 409 when its monthly cut contained a historical fund snapshot that embedded `managedAssetsJson` as a JSON array or object. The approval request and permissions were valid, but snapshot restoration expected that field to be a JSON string and stopped before creating the Expense.

Snapshot restoration now accepts both historical embedded JSON and the current string representation. Newly scheduled cuts persist the field as a string so future snapshots use one stable shape. The change does not rewrite historical cuts, approve receipts automatically, change balances or movements, or add a Flyway migration.
